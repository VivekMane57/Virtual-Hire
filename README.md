## 🧠 Overview

**Virtual-Hire** is an **AI + Machine Learning + Deep Learning powered interview automation platform** designed to enhance the recruitment experience.  
It helps recruiters analyze candidates using intelligent AI chat simulations, resume parsing, and real-time emotion/voice analytics.

The system combines **Natural Language Processing (NLP)** and **Deep Neural Networks (DNNs)** to evaluate communication, confidence, and technical responses during interviews.

## ✨ Key Features

✅ **AI Interview Simulation** – Uses Gemini & OpenAI APIs for intelligent Q&A chat  
✅ **Resume Analyzer** – ML-based scoring system for resume quality & skill matching  
✅ **Emotion Detection** – Deep Learning model (CNN + OpenCV) for facial emotion tracking  
✅ **Voice & Tone Analysis** – Detects speech clarity, confidence, and pauses  
✅ **Candidate Dashboard** – Displays insights, scores, and personality graph  
✅ **Recruiter Portal** – Candidate shortlist view & interview report access  
✅ **JWT Authentication** – Secure login & session management
